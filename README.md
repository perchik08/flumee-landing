# Flumee Landing

Одностраничный лендинг для Flumee — персонального ИИ-помощника для денег в Telegram.

## Стек

- React 18 + Vite 6 + TypeScript
- Tailwind CSS 3
- Framer Motion
- lucide-react

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Персонаж

Персонаж: `public/images/flumee-character.png`

(исходный файл `flumee-character.png.png` также поддерживается — скопирован в стандартное имя)

Путь в коде: `FLUMEE_CHARACTER_SRC` в `src/constants.ts`. Компонент: `FlumeeCharacter`.
